# OUTBREAK RUN — Stage 2

라스트 워의 슈팅 구간에서 영감을 얻은 독립형 HTML 프로토타입입니다. 원작 이미지와 음원을 복사하지 않고 Canvas로 폐허 도시, 주인공, 좀비 실루엣을 직접 그립니다.

## 현재 구현
- 반응형 슈팅 화면과 폐허가 된 도심 배경
- Canvas로 그린 창작 주인공 및 좀비 실루엣
- 작전 구역, 점수, 체력 HUD
- 움직이는 먼지/불씨 효과
- **키보드 이동:** ← → 방향키 또는 A / D
- **마우스와 터치 이동:** 게임 화면 위를 누른 채 좌우로 드래그
- **자동 발사:** 주인공이 일정 간격으로 빛나는 투사체 발사
- 데스크톱과 모바일 크기에 맞춘 UI

## 실행
`index.html`을 브라우저에서 열면 됩니다. 빌드 도구나 외부 라이브러리는 필요 없습니다.

## 현재 단계의 제한
총알은 화면을 향해 날아가는 시각 효과로 구현되어 있습니다. 적과의 충돌, 적 처치, 점수 변화, 실제 체력/게임오버 규칙은 아직 연결되지 않았으며 다음 단계에서 구현합니다.
