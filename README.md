# OUTBREAK RUN — Stage 3 (Straight-Fire Update)

라스트 워의 슈팅 구간에서 영감을 얻은 독립형 HTML 게임 프로토타입입니다. 원작의 이미지/리소스를 복사하지 않고 Canvas로 창작 배경과 캐릭터를 직접 그립니다.

## 현재 구현
- 반응형 Canvas 화면과 폐허가 된 도심 배경
- 키보드 이동: ← → 방향키 또는 A / D
- 마우스·터치 이동: 게임 화면 위에서 누른 채 좌우 드래그
- **탄환은 화면 위쪽으로 곧게 직선 발사됩니다. 적을 자동 추적하지 않습니다.**
- 적이 나타나면 플레이어가 좌우로 위치를 맞춰 탄환을 명중시켜야 합니다.
- 실제 적은 다섯 개의 출현 구역 중 하나에서 나타나며 화면 앞쪽으로 이동하면서 커집니다.
- 장식용으로 멈춰 보이던 배경 좀비를 제거했습니다.
- 적의 몸통 범위 안에 탄환이 닿으면 체력 감소, 처치 시 +100점
- 적이 플레이어에게 도달하면 체력 20 감소
- 체력이 0이 되면 게임 오버 및 다시 시작 버튼 표시

## 실행 / 조작
\`index.html\`을 브라우저에서 열면 됩니다. 외부 라이브러리나 빌드 도구는 필요하지 않습니다.

- PC: ← → 또는 A / D
- 마우스: 게임 화면 위에서 누른 채 좌우 드래그
- 태블릿/휴대폰: 화면을 좌우로 드래그
- 공격은 자동으로 반복 발사되지만, **조준은 자동이 아닙니다. 직접 좌우로 움직여 적과 탄환의 수직선을 맞춰야 합니다.**

## 참고한 게임 메커니즘
Last War의 슈팅 구간에 대한 공개 가이드들은 캐릭터가 자동 사격하며 플레이어가 좌우 이동으로 위치를 조절하고 장애물/위험 요소를 피하는 구조로 설명합니다. 이 프로토타입은 그중 좌우 위치 조절을 살리고, 사용자의 요청에 따라 자동 조준 대신 고정된 직선 탄환과 직접 조준을 사용합니다.
