# OUTBREAK RUN — Stage 1

라스트 워의 슈팅 구간에서 영감을 얻은 독립형 HTML 프로토타입입니다. 원작 이미지와 음원을 복사하지 않고 Canvas로 폐허 도시, 주인공, 멀리 있는 좀비 실루엣을 직접 그립니다.

## 1단계 완료 항목
- 반응형 슈팅 화면과 폐허가 된 도심 배경
- Canvas로 그린 창작 주인공 및 먼 거리의 좀비 실루엣
- 작전 구역, 점수, 체력 HUD
- 먼지/불씨 애니메이션
- 데스크톱과 모바일 크기에 맞춘 UI

## 실행
\`index.html\`을 브라우저에서 열면 됩니다. 빌드 도구나 외부 라이브러리는 필요 없습니다.

## 다음 단계
2단계에서 키보드/터치 이동과 자동 공격을 추가합니다. 현재 점수와 체력은 표시용이며 게임 규칙에 연결되어 있지 않습니다.
