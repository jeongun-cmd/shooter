# OUTBREAK RUN — Stage 3

라스트 워의 슈팅 구간에서 영감을 받은 독립형 HTML 게임 프로토타입입니다. 원작 이미지를 복사하지 않고 Canvas로 폐허 도시, 주인공, 좀비를 직접 그립니다.

## 현재 구현
- 반응형 Canvas 게임 화면과 폐허 도심 배경
- 키보드 이동: ← → 방향키 또는 A / D
- 마우스·터치 이동: 게임 화면 위에서 좌우 드래그
- 자동 조준 사격과 빛나는 투사체
- 좀비가 주기적으로 등장하고 앞으로 이동
- 투사체와 좀비의 충돌 판정 및 좀비 체력
- 좀비 처치 시 100점, 점수 HUD 갱신
- 좀비가 주인공 근처까지 접근하면 체력 20 감소
- 체력 상태 표시, 체력 0일 때 게임 오버 화면
- 다시 시작 버튼으로 점수/체력/적 초기화

## 실행
\`index.html\`을 브라우저에서 열면 됩니다. 설치나 외부 라이브러리가 필요하지 않습니다.

## 조작
- 컴퓨터: ← → 또는 A / D
- 마우스: 캔버스에서 누른 채 좌우 드래그
- 태블릿/휴대폰: 화면을 좌우로 드래그
- 공격은 자동으로 발사됩니다.
